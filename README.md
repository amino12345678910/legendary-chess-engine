# Legendary Chess Engine

A C++20 chess engine / training assistant project focused on board representation, legal move generation, position evaluation, and analysis.

## Why I built this
I built this project to strengthen my problem-solving, C++ programming, debugging, and algorithmic thinking.

## Current Features
- Board representation
- Legal move generation
- Basic position evaluation
- Command-line interaction
- Testing and debugging utilities

## Tech Stack
- C++20
- CMake
- Git

- Debugging logic-heavy code
- Thinking about correctness, performance, and edge cases
- Using AI tools to explore ideas while verifying outputs through tests and reasoning
